# راهنمای فارسی ترمینال ویندوز (RTL)

این مخزن نسخه‌ای آزمایشی و غیررسمی از [Windows Terminal](https://github.com/microsoft/terminal) است که برای نمایش متن‌های فارسی و راست‌به‌چپ (RTL) تنظیم شده است. در این شاخه، پشتیبانی دوجهتهٔ متن در تنظیمات ترمینال به‌طور پیش‌فرض فعال است. هدف، بهبود نمایش متن فارسی در خروجی برنامه‌های خط فرمان است؛ نتیجه ممکن است بسته به برنامه، فونت و نوع ورودی متفاوت باشد.

> **توجه:** این پروژه محصول یا انتشار رسمی Microsoft نیست و تضمینی برای رفع همهٔ مشکلات فارسی‌نویسی، شکل‌دهی حروف، ترتیب متن، یا ویرایش خط فرمان نمی‌دهد. تغییر فونت به‌تنهایی همیشه مشکل راست‌به‌چپ را حل نمی‌کند.

## دریافت نسخهٔ آماده

1. به صفحهٔ [اجرای ساخت در GitHub Actions](https://github.com/Tiredb0y/terminal/actions/workflows/rtl-build.yml) بروید و آخرین اجرای موفق را باز کنید. اگر وارد GitHub نشده‌اید، ممکن است برای دریافت فایل لازم باشد وارد حساب شوید.
2. از بخش **Artifacts**، فایل `WindowsTerminal-RTL-unsigned-MSIX` را دریافت و از حالت فشرده خارج کنید.
3. این بستهٔ آزمایشی امضا نشده است. برای ثبت آن به شکل توسعه‌دهنده، Developer Mode ویندوز و Windows SDK (ابزار `makeappx.exe`) لازم است. فایل `.msix` را در یک پوشهٔ خالی استخراج کنید، سپس manifest را ثبت کنید:

   ```powershell
   makeappx.exe unpack /p .\CascadiaPackage_0.0.1.0_x64.msix /d .\Terminal-RTL
   Add-AppxPackage -Register .\Terminal-RTL\AppxManifest.xml
   ```

   اگر `makeappx.exe` در PATH نیست، آن را از پوشهٔ نصب Windows SDK اجرا کنید. فایل `.msix` را مستقیماً با `-Register` ثبت نکنید. برای حذف بستهٔ آزمایشی:

   ```powershell
   Get-AppxPackage WindowsTerminalDev | Remove-AppxPackage
   ```

4. برنامه با هویت جداگانهٔ `WindowsTerminalDev` نصب می‌شود تا با نسخهٔ رسمی تداخل نداشته باشد. نام نمایشی می‌تواند «Terminal» باشد. پس از نصب build جدید، اگر alias فعال باشد با `tr` اجرا می‌شود. alias از `wtd` به `tr` تغییر کرده؛ برای پرهیز از تداخل احتمالی، اگر برنامه‌ای دیگر با نام `tr` دارید، پیش از فعال‌کردن alias آن را بررسی کنید. عمداً از `wt` استفاده نشده تا با نسخهٔ رسمی Windows Terminal تداخل نکند.

**پیش‌نیاز:** Windows 10 نسخهٔ 2004 (ساخت 19041) یا جدیدتر. بسته‌های unsigned را فقط وقتی نصب کنید که به منبع ساخت اعتماد دارید. این مخزن ممکن است نسخه‌های آزمایشی یا ناپایدار داشته باشد؛ تنظیمات مهم خود را پیش از آزمایش پشتیبان بگیرید.

## فارسی در PowerShell

Windows PowerShell 5.1 ممکن است با code page قدیمی اجرا شود. در تنظیمات پروفایل Windows Terminal، برای همان پروفایل PowerShell می‌توانید این دستور را به‌عنوان فرمان آغازین تنظیم کنید تا ورودی و خروجی UTF-8 شوند:

```powershell
$utf8 = [System.Text.UTF8Encoding]::new($false)
[Console]::InputEncoding = $utf8
[Console]::OutputEncoding = $utf8
$OutputEncoding = $utf8
```

در صورت نیاز، پیش از آن `chcp 65001` را اجرا کنید. این تنظیم کدگذاری متن را تغییر می‌دهد، نه جهت نمایش متن؛ جهت‌نمایی RTL را ترمینال مدیریت می‌کند. اجرای خودکار PowerShell profile scriptها ممکن است به‌دلیل Execution Policy سیستم محدود شده باشد؛ برای این راهنما لازم نیست policy امنیتی را تغییر دهید. تنظیمات PowerShell که همراه با نصب توسعه‌دهندهٔ این مخزن آمده مخصوص همان نصب است و جزئی از فایل‌های این مخزن نیست.

## ساخت از کد منبع

ساخت خودتان نیز ممکن است؛ دستورالعمل پیش‌نیازها و ساخت Windows Terminal در [README اصلی](README.md) و [راهنمای ساخت](doc/building.md) آمده است. این شاخه workflow ساخت unsigned MSIX را در GitHub Actions دارد. برای مشارکت، تغییرات را در شاخهٔ کاری خود آزمایش و بررسی کنید؛ اجرای ساخت به‌تنهایی تضمین نمی‌کند که همهٔ حالت‌های فارسی درست باشند.

## گزارش مشکل

هنگام گزارش مشکل، نسخهٔ Windows، نسخه/نام برنامه‌ای که متن را تولید می‌کند، فونت، مثال کوتاه از متن (ترجیحاً قابل کپی), و اینکه مشکل در **ترتیب RTL، اتصال حروف، ورودی/ویرایش، یا encoding** کدام است را ذکر کنید. رمز عبور، token یا اطلاعات خصوصی نفرستید.
